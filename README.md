# 🚀 Viral Games Studio

> **"Biz qlobal miqyasda viral, maraqlı və yüksək asılılıq (retention) yaradan oyunlar hazırlayırıq."**

Xoş gəlmisiniz! **Viral Games Studio** innovativ mexanikaları, sürətli prototipləşdirməni və dərin oyun təcrübəsini birləşdirərək milyonlarla oyunçunun marağına səbəb olacaq yeni nəsil oyun layihələri yaradan müstəqil oyun studiyası startup-ıdır.

---

## 🎮 Biz Nə Edirik?

* **Viral Mexanikalar (Core Loop Optimization):** Oyunçunu ilk 3 saniyədə cəlb edən intuitiv idarəetmə və güclü dopamin dövriyyəsi.
* **Məlumat Əsaslı İnkişaf (Data-Driven Retention):** Oyun daxili analitika, A/B testləri və yüksək LTV (Lifetime Value) hədəfli monetizasiya.
* **Dərin Strategiya və Asılılıq:** Həm təsadüfi (casual) istifadəçiləri, həm də taktiki qərarlar qəbul etməyi sevən strateqləri cəlb edən hibrid janrlar.

---

## 🏆 Flaqman Layihəmiz: Political Strategy Game

* **Janr:** Geopolitik Qlobal Strategiya / İdarəetmə Simulyatoru
* **Mühərrik:** Unity (C#)
* **Platformalar:** Android, iOS, Web
* **Əsas Xüsusiyyətlər:**
  * Real iqtisadiyyat, diplomatiya və hərbi balans sistemi
  * Ərazi fəthləri, resurs idarəetməsi və dinamik qərarlar
  * Mobil cihazlar üçün erqonomik, müasir və sürətli UI interfeysi
